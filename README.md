# ARCHER THE GREAT
A responsive static tribute to Archer with ten optimized photos, blue accents, a photo lightbox, sourced Boxer facts, and a demo inquiry form. The form does not send or store messages.

Deploy the repository root on Vercel with framework preset Other, no build command, and output directory `.`.

Photos are EXIF-oriented, stripped of metadata, resized to a maximum 1500 pixels, and converted to WebP. Gallery thumbnails are capped at 600 pixels. Original photos are not committed.
